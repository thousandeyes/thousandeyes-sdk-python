# OptimizationStatus

Lifecycle status of the alert rule optimization. This field describes recommendation state; it is not used to represent lookup availability. The alert-rule read operations return only `active`, because an `optimization` object is returned only when an authorized lookup finds an active optimization. The remaining values are the preserved lifecycle vocabulary; they are set by the system or through the ThousandEyes UI and are not returned by these operations.
